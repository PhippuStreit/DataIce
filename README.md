# Data Ice

Eine mobile, feste Glace-Formular-App mit Next.js, Prisma und SQLite im Development.

## Setup

1. `npm install`
2. `cp .env.example .env`
3. `npx prisma generate`
4. `npx prisma db push`
5. `npm run dev`

## Features

- feste, hardcodierte Formularstruktur
- mobile First UI mit Klick-Buttons
- serverseitige Validierung
- Speicherung in SQLite
- einfache Telemetrie- und Analytics-Auswertung
